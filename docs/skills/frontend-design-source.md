# Frontend Design Source Skill

## Core Direction

- choose a bold aesthetic direction before coding
- make the interface memorable instead of merely clean
- avoid generic AI styling and default visual stacks
- commit to intentional typography, color, spacing, and motion

## Required Design Questions

- what is the product for
- who uses it
- what tone should the interface express
- what single visual idea should be memorable

## Practical Rules

- pair a distinctive display font with a restrained body font
- prefer a strong visual identity over neutral sameness
- use motion to create high-impact moments rather than scattered noise
- embrace asymmetry, overlap, controlled density, or strong negative space when appropriate
- use atmosphere in the background instead of flat default surfaces

## Anti-Patterns

- no Arial, Inter, Roboto, or generic system-ui defaults as the main visual idea
- no purple-on-white gradient cliches
- no cookie-cutter dashboard layout that could fit any product
- no motion for motion's sake
