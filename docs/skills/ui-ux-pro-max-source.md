# UI/UX Pro Max Source Skill

## High-Priority Rules

### Accessibility

- maintain readable contrast
- show visible focus rings
- keep keyboard order aligned with visual order
- provide alt text and icon labels where needed

### Touch And Interaction

- minimum 44x44px touch targets
- primary actions must work without hover
- all clickable surfaces need cursor and feedback
- reserve space for loading content to avoid jumps

### Motion

- 150ms to 300ms for micro-interactions
- prefer transform and opacity over layout-changing animation
- respect reduced motion preferences

### Visual Quality

- use real SVG/icon systems instead of emojis
- avoid scale hovers that shift layout
- use trustworthy brand or league marks when available
- keep light mode borders and muted text visible

### Layout

- no hidden content behind fixed bars
- no accidental horizontal scroll on mobile
- use a consistent z-index scale
- maintain consistent max-width logic
