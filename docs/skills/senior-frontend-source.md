# Senior Frontend Source Skill

## Engineering Priorities

- keep frontend work production-grade and maintainable
- prefer incremental changes with clear architecture
- measure before optimizing, but keep performance in mind during implementation
- preserve testability and code clarity while improving UX

## Applied Rules For This Repo

- use TypeScript and explicit UI data models
- keep shared utilities reusable instead of embedding ad hoc logic in pages
- include loading, empty, and error states
- keep lint, build, and tests green after each meaningful slice
- document implementation plans before larger feature work

## Review Checklist

- component boundaries are clear
- interactions are accessible
- visual polish does not introduce fragile behavior
- data-heavy surfaces remain readable and responsive
