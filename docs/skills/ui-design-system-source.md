# UI Design System Source Skill

## System Goals

- keep one coherent token system
- define repeatable component behavior
- make theme decisions traceable and reusable
- preserve consistency across pages, cards, tables, explorers, and overlays

## Token Priorities

- color tokens for readable light and dark themes
- type scale for hierarchy without oversizing heroes
- spacing scale that supports dense data views
- shadow, border, and motion tokens for stable interaction feedback

## Applied Rules

- avoid competing global style layers
- use shared surface classes instead of per-page one-off styling
- align interactive states across cards, pills, nav items, and table rows
- document new system-level decisions so future phases stay consistent
